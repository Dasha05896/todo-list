# Todo List Web Application

This is a practical Django project for managing daily tasks.

## Functionality
- Create, edit and delete tasks (Tasks).
- Classify tasks using tags (Tags).
- Change task status (Complete/Undo) with one click.
- Sorting: uncompleted tasks are displayed first, from newest to oldest.
- Convenient interface based on Bootstrap 4 and Crispy Forms.

## Installation
1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`.
4. Run migrations: `python manage.py migrate`.
5. Start the server: `python manage.py runserver`.
